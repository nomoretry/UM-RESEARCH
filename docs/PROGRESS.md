# 港区与仓库的充电设施规划进展

- [固定设施调度](../results/fixed_facility_20261104/README.md)建立了单车跨任务的连续电量和站点功率约束。
- [两地投资](../results/investment_20261110/README.md)加入接口数量和付费接入容量。后续用[三个时间粒度](../results/timegrid_20261110/README.md)检查连接规则，再比较[港区接入功率和仓库插枪窗口](../results/boundary_20261110/README.md)。
- 在固定运输任务下，[已知放行延迟的投资实验](../results/known_delay_investment_20261111/metrics.json)给出每一档最低成本配置。[德国单次停靠记录](../results/dt_cargo_stop_20261111/event.json)提供可能充电时间的上界。
- [米兰论文复算](../studies/fresia-2025/)单独保存原文设备成本与年度电量核对。在固定重卡设施上比较不同购电策略，是后续的市场研究方向。
