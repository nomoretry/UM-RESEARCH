# App 事件采集核查

核查日期：2026-11-10。依据本次实际提供的 Codex App 工具说明；没有读取或批量列出其他聊天。

| 能力 | 实际可用边界 | 本项目采用方式 |
|---|---|---|
| `read_thread` | 要求明确的 threadId；按页返回状态和轮次摘要，可选包含截断的输出 | 不用它扫描其他聊天；不把摘要当完整聊天导出 |
| `wait_threads` | 对已知 threadId 返回状态/进度，最多八个目标；不是所有工具调用事件流 | 不用于通用动作日志 |
| `list_threads` | 可列出聊天元数据，但本任务明确禁止自动扫描其他聊天 | 本次未调用 |
| 当前聊天真实 ID/标题 | 本次可用输入没有提供经验证的当前聊天 ID/标题；相关读取工具需要先给出 ID | 使用稳定本地编号及明确的本地标题，platform_id 为 null；不从目录中的 UUID 推定平台 ID |
| 全量工具事件钩子、完整聊天自动导出 | 当前提供的工具中未发现可安装、已验证的此类接口 | 不承诺全量采集，不读取 App 内部数据库或会话存储 |

辅助脚本可以自动生成时间戳、登记来源提交、维护目录索引、追加动作日志并把明确日志文件提交到本地记录库；检查点记录显式路径与提交结果。实验登记只收集提交给它的 manifest 和文件证据，不自行监听求解器。

任务意图、研究判断、失败解释、外部工具动作及没有经过脚本的修改，仍需执行任务的助手或使用者显式调用日志命令并更新 STATUS/DECISIONS。中断、崩溃或未遵守指令可能留下缺口；下次从 Git 差异和产物补核，补录应标明补录及证据来源。

AGENTS.md 不会自行运行。没有部署后台服务、定时全聊天扫描或 Git 自动上传钩子。日志敏感词过滤只是辅助，写入前仍须审核；文件哈希不能证明实验结论正确。
