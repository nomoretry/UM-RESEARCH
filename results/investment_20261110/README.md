## 支持什么，不支持什么

在这个透明算例内，接口和功率是不同约束；开放仓库真实经过的窗口可以替代部分港区扩容，但不能消除最终港区的接口需求。联合选择接口与功率优于此处限定的单类投资方案；并非增加任何节点容量都会有收益。三车全部任务和初始电量没有为了制造优势而改变。

接口整槽占用不能轮换，故三车在最终槽都需补能时必须3接口；该结论需要时间粒度检验。费用目标不含峰值项，返回的港区111.111kW和仓库22.222kWh只是一个最优调度；同成本下仓库8.333–22.222kWh、港区111.111–125kW均可，不宣称最小峰值或唯一转移量。未建立共享上级电源，不能推出电网整体降峰。

不支持真实节约率、真实港口或德国运营验证、全年代表性、实际接入合格、换电、路线重排、V2G、储能、市场或潮流结论。下一任务是保持相同物理活动和费用，细化完整时间轴检验接口数/档位结果的离散化敏感性，再固定投资方案测试窗口扰动。
